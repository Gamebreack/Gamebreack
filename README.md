### How I work

- **Plan before code.** Agree the scope out loud, write it down, keep it small enough to reread.
- **Cheapest capable model.** A planner splits the work; cheap models do the routine parts, strong ones the hard parts.
- **The author never grades their own work.** Review and verification run in a fresh context.
- **Evidence over claims.** Passing tests and reviewer agreement are things to inspect, not proof.

### Currently building

- **[multi-agent-orchestration](https://github.com/Gamebreack/multi-agent-orchestration)** — turns the coding agent you already use into a planner. It hands work to cheaper or stronger roles, a fresh agent checks the result, and it commits only when asked. Plain Markdown, any harness.
- **[agent-verification](https://github.com/Gamebreack/agent-verification)** — `verify`, a skill that builds a contract from the original task, has fresh reviewers check the change against it, and returns a verdict backed by evidence. It never fixes anything. Passing tests are evidence, not proof.
- **[megaplan](https://github.com/Gamebreack/megaplan)** — a roadmap and backlog for agents, so the plan survives between sessions.
- **[flow-map](https://github.com/Gamebreack/flow-map)** — how a repo, several repos, a folder or a set of documents flows from A to B, in three small Mermaid diagrams checked against the sources and kept current.
